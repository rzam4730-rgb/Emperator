# Emperator React Dashboard Prototype

An isolated React + TypeScript + Vite RTL dashboard prototype. The existing frontend and Python/FastAPI backend are intentionally unchanged.

## Requirements

- Node.js 20.19+ or 22.12+ (current Vite requirements; verify your target Windows version before installing)

## Run locally

```bash
cd frontend-react
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build

```bash
npm run build
```

## Notes

- Dashboard metrics and order rows are demo data, not live API results.
- No existing frontend, backend, Electron, installer, or workflow files were modified.
- This prototype is not yet wired into the production app or Windows installer.
